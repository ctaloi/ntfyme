# NtfyMe landing page design

## Surface
- **Artifact:** `site/index.html`
- **Mode:** Persuade
- **Audience:** people who already use or evaluate ntfy and want a native Mac client

## Direction
The page is built from the app's own world: a Mac window, a Mac popover,
system typography, system grays, one accent blue. No gradient-marketing
hero, no feature-card grid. The first viewport proves the product by
showing the real app window with the real popover floating over it.

## Palette & type
- Ground: near-white Apple system gray (`#fbfbfd`)
- Text: macOS ink (`#1d1d1f`), secondary (`#6e6e73`)
- Accent: app blue (`#0a6cff`)
- Font: `-apple-system` / SF Pro stack, because the subject is a Mac app

## Composition
- Sticky hairline nav, quiet links, one clear Download pill
- Two-column hero: copy left, proof right
- Three compact fact blocks (not cards)
- One archive-detail screenshot, one compose screenshot
- Security note and open-source CTA beneath

## Non-goals
- No folder/grouping language
- No marketing superlatives
- No invented claims
- No generic SaaS illustration language
